Zine Exchange Club Architecture

Vanilla PHP zine exchange coordination platform

Tech Stack

  • • Vanilla PHP 8.3+ (no framework)
  • • Apache + mod_php
  • • MySQL / MariaDB
  • • SMTP relay (no auth)
  • • CSS + vanilla JS frontend

Exchange Flow

  • • Register → Confirm email
  • • Join cycle → Confirm participation
  • • Admin pairs → Confirm pairing
  • • Send zine → Receive zine
  • • Upload to gallery

Key Features

  • • 6 plugin-based pairing algorithms
  • • Question-based CAPTCHA
  • • Cron-driven reminder emails
  • • Email notification audit trail
  • • SQLite in-memory test suite
